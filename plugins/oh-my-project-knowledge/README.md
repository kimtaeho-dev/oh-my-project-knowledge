# oh-my-project-knowledge

> ⚠️ **DEPRECATED (2026-05)**
>
> 이 시스템은 [`oh-my-claude-setup`](../oh-my-claude-setup) v2.0.0의 슬림 도메인 맵(`.claude/DOMAIN_MAP.md`)으로 흡수되었습니다.
> 새 프로젝트에서는 `oh-my-claude-setup`을 사용하세요. marketplace에서는 더 이상 노출되지 않습니다.
>
> **흡수된 기능**
> - 도메인 → 파일 위치 매핑 (단일 파일, 자유 텍스트 형식)
>
> **폐기된 기능**
> - `{app}.{기능명_스네이크}` 기능 ID 컨벤션
> - FEATURES, ENTITIES, DEPENDENCY_MATRIX, SERVICE_FLOW, CHANGE_LOG 분리 문서 시스템
> - impacts/affected_by 양방향 영향 관계 정적 매트릭스
>
> **폐기 이유**: [Superpowers](https://github.com/obra/superpowers)를 메인 워크플로우로 채택하면서 정적 영향 관계 문서의 가치가 줄어들었습니다. brainstorming 스킬이 변경 시점에 동적으로 추론하는 것이 정확도와 토큰 효율 모두에서 더 낫습니다. 또한 표준 식별자 컨벤션을 사용할 사내 문화(VOC/이슈 라우팅 등)가 부재하여 컨벤션 학습/참조 비용이 가치를 초과했습니다.
>
> 코드는 학습 자산으로 보존됩니다.
